# MCP Server
MCP servers can provides the functionalities like:

- Resources : File-like data that can be ready by client( like API responses or file contents)
- Tools: Functions that can be called by the LLM(with user approval)
- Prompts: Pre- written templated that help users accomplish specific tasks

## Requirements
- Python 3.10 or higher
- uv as package manager
- Python MCP SDK 1.2.0 or higher
